bige-ops

OKS & pods

Kubernetes managé Outscale (OKS). Vous dimensionnez cluster + workloads ; Outscale opère le control plane. bige-ops génère specs et manifests — pas votre SRE à la place.

Cluster & nodepools

  • Topologie oks : cluster + nodepools (type Tina, count)
  • Formulaire Visual / CLI → maj directe de la simulation (pas d’interview en boucle)
  • apply --target oks via oks-cli embarqué

Pods / Deployments

  • Services (api, web, worker, DB…) → Deployments + Services sous oks/apps/
  • Réplicas : champ formulaire par service (service_config.*.replicas) → rewrite du setup, puis generate
  • deploy applique les manifests sur le cluster (kubectl)

Limites assumées

  • Policies réseau avancées, mesh, opérateurs custom : hors starter kit
  • Vous validez les YAML générés avant prod
  • Kubeconfig sensible reste local (pas dans le config-history)
