VMs Outscale

Composer une topologie machine (type Tina, disques, réseau), estimer, générer Terraform, apply sur votre compte. Le patch OS et le scale horizontal fins restent de votre côté.

Single-vm vs multi-vm

En single-vm, apps et souvent la data partagent une machine : simple pour démarrer, limites de blast radius évidentes. En multi-vm, vous séparez les rôles (app, worker, data…) sur plusieurs VMs dans le même Net — toujours via le layout, toujours avec estimate sur le sizing choisi.

Ce que le formulaire pilote

Type d’instance, volumes attachés, placement réseau, liens EIP / LBU selon le canvas. Chaque changement réécrit la simulation ; generate materialize le Terraform. Vous relisez, vous apply.

Kickoff ≠ babysitting

Images OMI, SSH, hardening, monitoring avancé, scaling agressif : hors starter kit. Quand la charge monte, c’est à vous de gérer — voir périmètre.

Alternative Kubernetes managé : OKS & pods. Data et backups objet : bases, OOS.
