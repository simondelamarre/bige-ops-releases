bige-ops

VMs Outscale

On démarre la topologie. Type Tina, subnets, volumes, EIP, LBU — depuis Visual ou CLI. Le run fin (patch OS, monitoring avancé) reste le vôtre.

Ce que bige-ops fait

  • Stacks single-vm / multi-vm dans une simulation
  • Inspector : type d’instance, disques, réseau — formulaire → maj du setup tout de suite
  • generate → Terraform (materialization), puis plan / apply sur votre compte
  • Estimate catalogue sur le sizing choisi (indicatif)

Ce que vous assumez

  • Images OMI / SSH / hardening
  • Choix prod vs projection, apply réel
  • Ops quotidien une fois la VM live

Flux typique

Visual → drop VM / stack → formulaire sizing → Save + generate → Workspace plan/apply. Ou CLI bige-ops add stack --topology multi-vm.
