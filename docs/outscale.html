bige-ops Gratuit

Catalogue Outscale

Les services Outscale en une page, avec ce que bige-ops en fait : créé, réglé par défaut, observé, posé sur le canvas, ou présent au catalogue de prix.

Règle de lecture. Créé = generate + apply. Auto = créé par un module, avec des réglages par défaut. Observé = lu à l’inventaire, sans Terraform de création. Canvas = simulation et YAML seulement. Prix = catalogue de prix, sans composant. Cockpit / API = se règle directement chez Outscale.

Ce que ça implique

Ce qui est marqué Créé passe par Visual → generate → plan → apply et produit une configuration conforme à Outscale (Net, VMs, volumes, LBU, OOS, OKS via oks-cli). Le reste est dit ici, service par service.
