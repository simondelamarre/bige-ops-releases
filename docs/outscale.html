bige-ops Beta démo

Catalogue Outscale

Tout ce qu’Outscale propose, en une page — avec le niveau de support réel de bige-ops. Pas d’aspiration : créé, observé, décoratif, prix seulement, ou hors périmètre.

Règle de lecture. Chaque ligne dit ce qu’Outscale propose et ce que bige-ops fait vraiment. Créé = generate + apply. Observé = inventaire / canvas, pas de TF create. Décoratif = canvas / YAML seulement. Prix seulement = catalogue embarqué, pas de modèle. Hors périmètre = documenté pour ne pas mentir par omission.

Ce que ça implique

Si c’est marqué Créé, Visual → generate → plan → apply doit produire une config Outscale-conforme (vérifié pour Net, VM, LBU HTTP, volumes, OOS, OKS via oks-cli). Si c’est autre chose, la doc le dit ici — pas dans un coin de glossaire.
