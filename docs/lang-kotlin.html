Kotlin sur Outscale

Kotlin a gagné le serveur après Android : concision, null-safety, coroutines. Ktor pour des services légers, Spring Boot en Kotlin pour profiter de tout l’écosystème Spring. Sur Outscale, bige-ops les traite comme des services JVM.

En bref. Kotlin tourne sur la JVM : runtime java dans bige-ops (port 8080, 1 GiB), image construite par Gradle depuis ton Dockerfile.

Frameworks et bibliothèques

Deux voies principales côté serveur.

Ktor

Le framework serveur de l’équipe Kotlin : asynchrone par coroutines, modulaire par plugins, moteurs Netty ou CIO.

documentation officielle · Ktor sur OpenCVE

Spring Boot en Kotlin

Spring prend Kotlin en charge de première classe : DSL de beans, coroutines dans WebFlux, extensions Kotlin pour Spring Data.

documentation officielle · Spring Boot sur OpenCVE · Kotlin sur OpenCVE

Gradle Kotlin DSL

Le build idiomatique d’un projet Kotlin (build.gradle.kts), qui produit un JAR exécutable pour l’image.

documentation officielle · Gradle sur OpenCVE

Faire tourner Kotlin sur Outscale avec bige-ops

Un service Kotlin se déclare en runtime java : 1 GiB et le port 8080 par défaut, ajustables par service (memory_mb, réplicas, HPA sur OKS). Ktor tient souvent dans 512 MiB.

Versions à épingler

Épingle la version de Kotlin et du plugin Gradle dans build.gradle.kts, et un JDK LTS (25 ou 21) dans l’image. Docs : Kotlin · CVE : Kotlin sur OpenCVE · Ktor sur OpenCVE.

OpenCVE, le référentiel CVE de bige-ops

Pour savoir quelles vulnérabilités touchent les briques de ta stack, bige-ops s’appuie sur OpenCVE. OpenCVE agrège les CVE publiées (NVD, MITRE, catalogue KEV de la CISA…), les enrichit avec les scores CVSS et EPSS et les range par fournisseur et par produit, consultables dans son explorateur. Le projet est open source : son code, ses issues et les contributions de sa communauté vivent sur GitHub, et il s’installe aussi chez toi. Merci à ses mainteneurs et à tous ceux qui font vivre ce référentiel : c’est grâce à eux que chaque composant de ta simulation a sa fiche CVE à jour.
