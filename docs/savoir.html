bige-ops Beta démo

Ce que bige-ops sait — et ce qu’il ne sait pas toujours

Un starter kit embarque un instantané du monde Outscale (catalogue, topologies, materialization). Ce n’est pas la vérité commerciale ni le catalogue live. Les experts, ce sont les équipes Outscale — pas nous.

Commerciaux & tech Outscale : écrivez sur GitHub. Avancées d’offre, déceptions, remarques sur l’outil, l’usage ou le pricing — ouvrez une issue ou une discussion / PR sur bige-ops-releases. Pour le moment c’est le canal direct. Vous corrigez la carte ; on ajuste le kit.

Ce que le kit sait (aujourd’hui)

  • Estimate à partir d’un catalogue public embarqué (indicatif € HT/mois).
  • Topologies produit : mono-VM / multi-VM, OKS, volumes BSU types connus du kit (ex. gp2 / io1), OOS, layouts Visual.
  • Materialization : Terraform / specs / YAML — apply / deploy sur votre compte.
  • Limites assumées du kickoff : périmètre.

Ce qu’il ne sait pas toujours

  • Pricing commercial — devis, remises, options tenant, facture réelle. Pas de feed live. Estimate ≠ quote.
  • Capacités d’offre qui bougent — régions, types d’instance, stockage, SKUs SecNumCloud vs public. Le kit peut être en retard ou simplifier.
  • Votre négo et le discours commercial terrain — hors scope outil.

Exemple : NVMe

Selon notre lecture actuelle du terrain / catalogue embarqué, bige-ops ne modélise pas de NVMe — y compris sur SecNumCloud. Ce n’est pas une promesse « Outscale n’aura jamais de NVMe » : ça pourrait changer demain. Quand l’offre évolue, le kit doit être mis à jour — idéalement signalé par ceux qui connaissent le catalogue pour de vrai.

Même logique pour d’autres capacités (nouveaux types Tina, volumes, régions, quotas) : si le Visual / l’estimate ne proposent pas X, ce n’est pas forcément « X n’existe pas » — parfois « le snapshot du kit ne le sait pas encore ».

Canal GitHub (pour le moment)

Pas de portail partenaire dédié. Pour les commerciaux et tech Outscale :

  • Nouvelle issue — avancée d’offre, erreur de pricing, capability manquante, remarque d’usage, déception produit.
  • PR sur la doc / le message landing si vous voulez corriger un libellé (VPS, SKU, région…).

Soyez francs : progrès et déceptions. L’outil sert le kickoff ; la vérité offre / prix reste la vôtre.
