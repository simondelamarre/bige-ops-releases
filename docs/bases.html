Bases de données

Presets par type. Vous choisissez Postgres, Mongo, Redis… Le formulaire applique réplicas / sizing / nœuds gérés et met à jour le setup tout de suite — sans questionnaire en boucle. Le DBA fin et le backup stratégie restent les vôtres.

Types & presets

Type Preset typique Via formulaire
Postgres Image catalogue, volume data Taille, attache VM / pod, réplicas OKS
MongoDB Service data colocalisé ou pod Réplicas Deployment (OKS), ressources
Redis Cache léger Réplicas, coloc VM app ou OKS
Custom Image + port Mêmes champs sizing / réplicas

Formulaire → setup, sans plus de questions

Dans Visual (inspector) : vous changez un champ (réplicas, type de nœud nodepool, GiB volume…). La simulation / project.yaml est mis à jour directement. Save + generate materialize Terraform / manifests. Pas d’assistant qui redemande dix fois la même chose.

  • OKS : réplicas pods = service_config.*.replicas
  • Nodepools : count + node-type gérés sur le cluster
  • VMs : DB souvent colocalisée / liée — sizing machine + volume

Hors scope (volontaire)

  • Tuning SQL / indexes / sharding avancé
  • Opérateurs K8s spécialisés non générés par défaut
  • Garantir la HA prod sans relecture humaine
