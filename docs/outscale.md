# Catalogue Outscale

Matrice des services Outscale dans bige-ops : créé, auto, observé, canvas, prix, ou réglé dans Cockpit / API. Points clés : LBU HTTPS par certificat EIM, OOS protégé contre la destruction, OKS en `eu-west-2` et `cloudgouv-eu-west-1`, trafic sortant à 0 € HT au catalogue public dans quatre Régions sur cinq.
