# Ce que bige-ops sait

bige-ops est un **simulateur** pour Outscale. Il embarque le catalogue public Outscale, les topologies de référence et tout ce qu’il faut pour générer puis déployer ta stack sur ton compte.

- **Estimation** : coût mensuel € HT sur le catalogue public Outscale, synchronisable via l’API.
- **Topologies** : mono-VM, multi-VM, OKS, avec volumes BSU, Object Storage et LBU.
- **Materialization** : Terraform et manifests Kubernetes générés, puis plan, apply et deploy sur ton compte.
- **Analyses** : contrôles avant déploiement, risques sur les données, CVE des dépôts (clé OpenCVE).

**Chez Outscale** : ta facture et tes offres commerciales (l’estimation repose sur la grille publique), et les nouveautés de l’offre, intégrées au fil des versions.
