bige-ops Gratuit

Réseau avancé

Réseau · ouvrir ou non dit quoi exposer. Cette page dit ce que bige-ops matérialise côté Outscale, ressource par ressource, et ce qu’il se contente de lire.

Quatre niveaux, un seul vocabulaire. Créé : bige-ops génère le Terraform et tu le règles. Auto : créé par le module réseau, avec des réglages par défaut. Observé : lu depuis ton compte, jamais réécrit. Canvas : visible sur le canvas et dans le YAML, sans Terraform derrière.

Le NAT, à activer pour sortir

Le NAT est à false par défaut. Une VM data en subnet privé n’a alors aucune sortie Internet : pas d’apt, pas de docker pull, pas de webhook sortant. Si ton layout doit sortir, active le NAT (enable_nat) : bige-ops crée le NAT service dans le subnet public, avec son IP publique, et la route 0.0.0.0/0 du subnet privé vers lui. Un NAT service se facture à l’heure.

Un seul NAT service sert tous les subnets privés du Net, derrière une seule IP publique : c’est aussi ce qui économise ton quota d’IP publiques. La validation de bige-ops signale le cas d’une VM privée sans NAT.

IP publiques : ce qui est facturé

Le catalogue public Outscale facture à l’heure les IP publiques « additionnelles » et celles qui ne sont associées à aucune VM démarrée. L’inventaire repère les IP orphelines et l’estimation de projet les compte. Dans l’inspector, un composant IP publique se rattache à sa VM cible par un sélecteur.

Bon à savoir : dans un Net, l’association d’une IP publique à une VM est persistante à travers les arrêts et redémarrages ; c’est le tag osc.fcu.eip.auto-attach qui permet de fixer une IP précise à une VM au démarrage.

Pourquoi « observé » plutôt que « géré »

Peering, VPN et security groups importés : bige-ops les lit, les écrit en composant observé, et les exclut de la génération Terraform. Un apply ne recrée jamais par-dessus une interconnexion réglée à la main, et ne la détruit jamais parce qu’elle n’était pas dans le YAML.

Ces objets se règlent dans Cockpit ou par l’API Outscale ; bige-ops les affiche pour que ta simulation reste fidèle au compte.
