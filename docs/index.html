01 / CONNECTERTout commence par ton projet.

01 / PaaS + BaaS → IaaS

Tu as déjà une app. Pas encore ton infra.

Un front sur Vercel ou Heroku, une base sur Supabase ou MongoDB Atlas, des fichiers ailleurs. bige-ops t’aide à préparer leur nouvelle maison, sur ton propre compte cloud.

Comprendre cette étape ↗

02 / Compte → dépôt → branche

Connecte GitHub. Choisis ce qui part.

Relie ton compte, sélectionne le dépôt et la branche. Identifie le front, l’API et les workers à déployer : ton code reste dans ton GitHub.

Comprendre cette étape ↗

03 / Visual → Terraform

Dessine ce que les plateformes te cachaient.

Place ton application, tes bases et leur stockage. bige-ops traduit cette architecture en Terraform lisible et versionné. Tu pilotes le résultat sans écrire toute la plomberie DevOps.

Comprendre cette étape ↗

04 / HTTPS → app → base privée

Ouvre ton app. Protège le reste.

Une entrée HTTPS pour tes utilisateurs. L’application et la base communiquent en privé. Tu choisis les connexions, les machines et la région qui héberge ta stack.

Comprendre cette étape ↗

05 / Scanner → comprendre → corriger

Avant de partir, regarde les risques.

Le scan relie les failles du code et des dépendances à leur contexte. CWE, CVE, route exposée, version corrigée : prépare une issue GitHub pour agir.

Comprendre cette étape ↗

06 / Copier → vérifier → basculer

Tes données deviennent souveraines.

Choisis un cloud souverain et une région adaptée. Migre ta base, copie tes objets, puis vérifie avant de basculer : tes données rejoignent une infrastructure sous ton contrôle.

Comprendre cette étape ↗

07 / Build sur VM / GitHub Actions → GHCR

Ton code devient une image prête à tourner.

Construis sur la VM, ou prépare une CI GitHub Actions qui construit et publie dans ton GHCR privé. Tu relis la pull request proposée avant de l’intégrer.

Comprendre cette étape ↗

08 / Test local → plan → déploiement

Du test local au vrai déploiement.

Teste ta stack sur ton poste. Relis le plan des ressources, confirme la cible, puis déploie le code choisi sur ton compte. L’infrastructure reste à toi.

Comprendre cette étape ↗

09 / Pause · Start · Restart · Deploy

Et demain, tu gardes la main.

Mets en pause ou démarre les VM compatibles, redémarre un service, consulte ses logs. Choisis une branche à déployer et suis les opérations depuis la même app gratuite.

Voir les opérations ↗
