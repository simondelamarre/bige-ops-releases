FAQ

Faut-il un compte cloud ?
Non pour commencer : projection offline. Oui pour inventaire / plan / apply (aujourd’hui : Outscale).
Où sont les secrets ?
Sur votre poste (coffre local). Rien synchronisé vers un backend bige-ops. Détail.
Gatekeeper macOS bloque l’app ?
Pas notarisé. Voir installer & Gatekeeper.
Et les autres clouds ?
Outscale est live. Suivent Scaleway, OVHcloud, AWS, Azure, GCP, Fly.io — voir Clouds. Suivi sur les issues.
Où vont mes clés LLM ?
Chez toi (Settings), puis chez le provider. Pas de rétention côté bige-ops. Agent.
