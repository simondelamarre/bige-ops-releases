Dessinez votre stack. Voyez le prix. Déployez.

bige-ops est une application gratuite, installée sur votre poste. Elle conçoit votre infrastructure cloud, la chiffre, vérifie ses failles et la déploie sur votre compte, aujourd’hui chez Outscale. Sans équipe DevOps.

brew install --cask simondelamarre/bige-ops/bige-ops

macOS avec Homebrew. Linux : AppImage ou .deb. Gratuit, sans carte bancaire, sans compte cloud pour commencer.

En clair

Le sujet. Mettre une application en ligne sur un vrai cloud : réseau, machines, bases de données, sauvegardes, sécurité. Un métier à part entière, d’habitude confié à une équipe DevOps.

Pourquoi s’en occuper. C’est là que se jouent votre facture, l’endroit où vivent vos données et la sécurité de vos clients. Un mauvais réglage se paie chaque mois, ou le jour d’un incident.

Utile pour vous ? Sans équipe DevOps, bige-ops fait le travail de départ : il dessine votre stack, la chiffre, vérifie ses failles et la déploie sur votre compte. Avec une équipe et une infrastructure qui tournent déjà, il apporte un second regard sur le prix et sur les failles.

Soyons honnêtes. bige-ops ne remplace pas un expert sur une infra critique. Il estime sur les prix publics, hors remises négociées. Il déploie des applications en conteneurs, et le HTTPS passe par un load balancer avec votre certificat. Tout est écrit dans ce qu’il sait faire, et ce qu’il ne sait pas.

Pourquoi le faire. Pour connaître le prix avant la facture, garder vos données en France sur un cloud qualifié, et corriger vos failles avant qu’un client ne les trouve.

Et pourquoi pas. C’est gratuit, cela tourne sur votre poste, sans compte cloud pour commencer, et vos secrets restent dans un coffre local. Si vous arrêtez, votre stack reste un simple fichier dans votre Git.

Comment bige-ops trouve vos failles

  1. Il lit le code de vos dépôts, sur votre poste.
  2. Il repère les pages et les API que votre application expose, et vérifie qu’elles demandent une connexion.
  3. Il cherche les erreurs classiques : mots de passe écrits en clair, requêtes à la base construites avec ce que tape l’utilisateur, API ouverte à n’importe quel site.
  4. Il compare vos bibliothèques à la base publique des failles connues (OSV) et, avec votre clé OpenCVE, votre stack au registre mondial des failles (CVE).
  5. Il classe tout par urgence : ce qui est exposé à Internet d’abord.

Pourquoi le refaire vous-même ? C’est chez vous, et c’est gratuit.
