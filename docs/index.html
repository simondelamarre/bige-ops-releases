Le problème

Le cloud Outscale ne devrait pas commencer dans un tableur.

Terraform à vide. SKUs Tina à coller. Un prix qu’on découvre trop tard. Déployer devient un projet avant même d’avoir une architecture.

La solution

Une app desktop gratuite. Vous composez le layout, vous voyez le €, vous déployez sur votre compte Outscale. En local. En trois gestes.

Layout→ Estimate→ Deploy

brew tap simondelamarre/bige-ops && brew install --cask bige-ops
