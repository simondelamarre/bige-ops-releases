bige-ops · Outscale & SecNumCloud

Composez. Estimez. Déployez.

Le starter kit Outscale — une app desktop gratuite pour designer votre stack, lire le € HT/mois, puis appliquer sur votre compte.

Télécharger macOS Télécharger Linux

brew tap simondelamarre/bige-ops && brew install --cask bige-ops

Trois gestes. C’est tout.

Pas de page blanche Terraform. Pas de tableur de SKU. Vous voyez la stack, le coût, puis vous appliquez.

Composez

Choisissez un layout, glissez VMs, volumes, réseau, OKS. Le canvas montre la topologie tout de suite.

Estimez

Le catalogue public Outscale calcule un € HT/mois indicatif — avant même d’avoir un compte.

Déployez

Générez Terraform / OKS, planifiez, appliquez sur votre tenant — y compris SecNumCloud.

Simple à dire. Honnête à l’usage.

Local-first. Gratuit. La facture cloud reste la vôtre.

Sans compte pour commencer

Mode projection : vous dessinez et estimez hors-ligne. Le login Outscale arrive quand vous voulez inventory / plan / apply.

Souverain par design

Vos credentials restent sur votre machine. Pas de SaaS de contrôle chez nous. Régions eu-west-2 et SecNumCloud.

GUI et CLI, même moteur

Ce que vous composez à l’écran, vous l’automatisez en CLI. Une vérité, deux interfaces.

Limites dites à voix haute

Ce que le kit sait — et ce qu’il ne sait pas — est documenté. Lire sait / ne sait pas et le périmètre.
