bige-ops

Free desktop app for Outscale. Design the stack · see the € · deploy when you’re ready. Fully local.

Download macOS Download Linux

brew tap simondelamarre/bige-ops && brew install --cask bige-ops

Quick start

  • Install the app (download or Homebrew).
  • Open a layout, check the estimate, deploy on your Outscale account.
  • Regions: eu-west-2, cloudgouv-eu-west-1 (SecNumCloud).

Docs

  • App is free. Your Outscale bill stays yours.
  • Runs on your machine — no hosted control plane.
  • Same engine in the GUI and the CLI.
  • More detail: GitHub README.
