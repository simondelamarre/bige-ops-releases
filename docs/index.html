Pricing

Estimations indicatives — pas un devis Outscale.

Avant même d’avoir un account, vous obtenez vos premières stacks et des à partir du catalogue public embarqué. Utile pour projeter et comparer — pas pour promettre la réalité commerciale de votre facture.

Le prix réel dépend de votre tenant, de vos négos, options et conditions Outscale. bige-ops n’est pas connecté en temps réel au pricing cloud : le catalogue peut évoluer, décaler, ou différer de ce que vous facture Outscale.

Sécurité

Pas de SaaS secrets. Vos credentials, votre responsabilité.

bige-ops ne propose aucun vault partagé et aucun coffre cloud à nous. Rien n’est synchronisé vers un backend bige-ops — pas de partage SaaS de vos clés avec l’outil.

Les secrets d’infra “réels” (accès runtime, credentials cloud une fois la stack live) vivent côté Outscale après deploy — c’est le cloud qui les détient, pas nous. Pour travailler en local, vous pouvez enregistrer credentials / valeurs de coffre sur votre machine (fichiers locaux). Si vous avez déjà un vault d’entreprise, vous restez libre de l’utiliser en dehors de bige-ops : l’app n’impose pas le sien.

Vos secrets → votre responsabilité : sécurisez le poste (chiffrement disque, session lock), gérez qui a accès à la machine. On ne stocke pas vos clés “quelque part pour vous”.

Git privé

Simulations versionnées sur votre repo — jamais de secrets dessus.

Chaque vit d’abord en local. Quand vous voulez un historique d’équipe, vous poussez vers un repo Git privé à vous — typiquement un *-infra dédié à la config. Une branche = une variante (main pour le live, sim/… pour les drafts).

Ce repo ne sert qu’à ça : project.yaml, layouts, Terraform généré, specs — l’historique de la stack. Pas le monorepo applicatif, pas le pipeline de deploy app. On ne mélange pas code produit et gestion d’infra : le repo app clone/deploy d’un côté, le versionne la simulation de l’autre.

Aucun secret ne part : pas de PEM, pas de .env, pas de tfvars, pas de kubeconfig, pas de state. Credentials restent dans le coffre local. Git = blueprint versionné, machine = keys.
