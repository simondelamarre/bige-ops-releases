FAQ

Faut-il un compte Outscale ?
Non pour commencer : projection offline. Oui pour inventory / plan / apply.
Où sont les secrets ?
Sur votre poste (coffre local). Rien synchronisé vers un backend bige-ops. Détail.
Gatekeeper macOS bloque l’app ?
Pas notarisé. Voir installer & Gatekeeper.
Et les autres clouds ?
Outscale d’abord (prêt). Autres providers en WIP — on ne se présente pas comme généraliste tant que ce n’est pas vrai. Suivi sur les issues.
Où vont mes clés LLM ?
Chez toi (Settings), puis chez le provider (Anthropic, OpenAI…). Pas de rétention côté bige-ops. Agent · Secrets.
