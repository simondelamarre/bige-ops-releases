LBU · l’entrée publique

Le LBU est la porte d’entrée HTTP de vos layouts multi-VM. bige-ops en crée un, avec un ou plusieurs listeners, et attache vos VMs derrière. Au-delà de ça, c’est votre console Outscale.

À retenir. Un LBU porte un nom DNS, pas une EIP. Le public tape le DNS du load balancer ; vos VMs restent derrière, sans IP publique.

Ce que bige-ops crée

  • Sept des huit layouts nommés créent un LBU. Seul node-lite, qui est mono-VM, n’en a pas : il expose une EIP.
  • Le scheme : internet-facing ou internal.
  • Un ou plusieurs listeners HTTP/TCP (les layouts avec web + api en posent souvent deux).
  • Les VMs backend attachées (backend_vms).
  • Un health check Outscale-conforme (check_interval, path, port, seuils) via outscale_load_balancer_attributes.
  • Les ports backend ouverts sur le security group default (dérivés des listeners — pas seulement 3000–3001).
Ready to deploy (HTTP). Visual → Enregistrer → generate → plan → apply produit un LBU Net sur le subnet public, branché sur vos VMs app, avec health check valide côté provider Outscale.

Ce que bige-ops ne crée pas

Pas de HTTPS généré. Les listeners produits sont en HTTP ou TCP. Aucune ressource de certificat n’est générée. Si vous voulez du TLS, la terminaison se fait dans la console Outscale ou en amont du LBU.

Plusieurs listenersoui — Visual et layouts
Health check (intervalle, seuils, timeout, path)oui — schéma provider (check_interval)
Sticky sessions, choix d’algorithmenon
Certificat / terminaison TLSnon

Un LBU importé est un croquis

L’inventaire liste vos load balancers existants. L’import en écrit un composant marqué observé : sans listeners, sans backends, et exclu du Terraform de création. C’est volontaire — un apply ne doit pas recréer par-dessus un LBU que vous avez réglé à la main. Dans Visual, Enregistrer est désactivé sur ces nœuds.

Security groups et LBU

Le LBU a ses propres règles côté Outscale, distinctes de celles des VMs qu’il sert. Ouvrir le listener ne suffit pas si le SG de la VM backend ne laisse pas entrer le load balancer. Les principes d’exposition sont sur Réseau · ouvrir ou non.
