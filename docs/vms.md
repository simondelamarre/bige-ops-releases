# VMs & VPS

- **VM** = terme produit bige-ops (instance Tina).
- **VPS** = libellé catalogue / marketing Outscale pour le même type de ressource.
- **Mono-VM** (code `single-vm`) : une VM `*-all` — apps + souvent data.
- **Multi-VM** (code `multi-vm`) : rôles séparés (app / worker / data).
- Puis : generate → **apply** (infra) → **deploy** (apps).
